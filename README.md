# Drill-Sortierer

Installierbare Web-App, um übrig gebliebene Diamond-Painting-Drills zu
erfassen und zu sortieren.

**App:** https://gerjocad.github.io/drill-sortierer/
Auf Android in Chrome öffnen → Menü ⋮ → **App installieren**.

- **Live-Kamera:** Kreis auf einen Drill richten – Farbe, Box-Code und
  nächste DMC-Nummer erscheinen sofort. Mit Licht und Weißabgleich.
- Außerdem: Foto/Galerie, Hex-Code oder DMC-Nummer eingeben.
- **Box-Code** wie `BL-2`: Farbfamilie + Helligkeit (1 sehr hell … 5 sehr
  dunkel). Gleiche und ähnliche Farben landen in derselben Box.
- Liste ähnlicher Farbpaare zum Zusammenlegen, CSV-Export, Backup/Import.

Die Daten bleiben auf dem Handy (Browser-Speicher). Ab und zu „Backup“ machen.

Die Dateien hier sind gebaut; die Quellen (`src/`, `build.py`) liegen im
Ordner `diamonds/` des Projekts ARAQ.
